# Tic-Tac-Toe (Java Swing & Web)

A simple, interactive 2-player Tic-Tac-Toe game available as both a native **Java Swing desktop application** and a **responsive web application**.


## Features
* **Dual Implementation:** Choose between playing on the desktop or directly in your browser.
* **Turn Management:** Live status display tracking current turns (`Player X` / `Player O`).
* **Win & Draw Logic:** Automatic check for horizontal, vertical, and diagonal win conditions or ties.
* **Clean UI:** Simple grid layout designed to replicate classic desktop GUI styling.


## 💻 1. Web Application

### Live Demo
If hosted via GitHub Pages, you can play directly in your browser:
`https://YOUR-GITHUB-USERNAME.github.io/TicTacToeWeb/`

### Running Locally
1. Open the repository root folder.
2. Double-click **`index.html`** to open and play the game in any web browser.
